# ALX Backend

This repository contains **backend** specialization projects: pagination, caching, i18n, and a queuing system in JavaScript. Each folder is a project; this README explains what each folder is for, what the main files do, and how to run the exercises.

## Structure

* [0x00. Pagination](./0x00-pagination)
* [0x01. Caching](./0x01-caching)
* [0x02. i18n](./0x02-i18n)
* [0x03. Queuing system in JS](./0x03-queuing_system_in_js)

| Folder | Topic | What you'll practice |
|--------|-------|----------------------|
| [0x00-pagination](./0x00-pagination) | API pagination | Page/size params, hypermedia links |
| [0x01-caching](./0x01-caching) | Caching | Cache strategies, Redis or in-memory |
| [0x02-i18n](./0x02-i18n) | Internationalization | Locales, translation, Flask-Babel |
| [0x03-queuing_system_in_js](./0x03-queuing_system_in_js) | Job queues | Redis, Bull/Kue, workers |

## Prerequisites

- Python 3, Flask (for Python tasks)
- Node.js, Redis (for queuing system)
- See each folder's README for specific dependencies.

## Quick reference

- Run the API or scripts as indicated in each project folder's README.
